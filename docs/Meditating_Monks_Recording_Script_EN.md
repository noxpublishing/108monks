# Meditating Monks · Recording script · 0.2.0 EN

## Language and delivery

All editorial narration is English. Tibetan prayers and Sanskrit mantras remain in their original recitation language. The English narration is original project copy, not a literal translation of the Tibetan prayer heard in the other channel.

Paste only the text inside a script block into the speech text field. Do not speak titles, filenames, production notes, or voice-design prompts. Record one file per section. Narration is spoken once, not sung or looped. Leave the quiet phase silent.

## English narration voice brief

Use this in the separate voice-design field, not the narration text field:

```text
A calm adult English-speaking narrator with clear, natural diction and a warm, restrained delivery. Speak slowly enough to leave space between phrases, but without an exaggerated meditation-app style. A gentle, ordinary speaking voice, not singing, whispering, preaching, or dramatic acting. Clean, dry studio sound. Do not imitate any identifiable person.
```

## Audio handover

Keep separate original WAV exports where available, without a music bed or baked-in choir. Keep all syllables intact. For a mantra loop, select exactly one complete, checked repetition from the raw take; three recorded repetitions must not be counted as one. Use the duration of the checked recording to propose timing changes instead of rushing the prayer to fit an arbitrary phase.

The supplied import plan is a draft mapping, not a release approval. No audio, rights evidence, pronunciation approval, or religious endorsement is included.

## App integration

Use the v0.2.0 repository. Its default practice profile is `public-compassion-en.json`. Narration filenames end in `_en_v01.wav`. Files ending in `_de_v01.wav` from the old plan are intentionally not accepted by the current default import mapping. Do not merely rename a German audio recording.

```bash
python -m app.cli audio-prepare /path/to/your/wavs --output /private/path/audio-draft.json
python -m app.cli audio-probe /path/to/your/wavs/05_mani_v01.wav
```

Then check pronunciation, source and output rights, cut boundaries, phase assignments, and timing before approving any asset. Follow `docs/AUDIO_WORKFLOW.de.md` in the repository.
