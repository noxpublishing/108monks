# Contributing

Keep the core lightweight, self-hostable and transparent. Do not add an LLM merely to repeat known text.

Practice packs must name sources and distinguish a traditional text from a modern arrangement. Do not submit restricted/private texts, unauthorized translations or recordings, cloned voices, or claimed endorsements. A content review must not be represented as an initiation or religious authorization.

Tests must cover timeline boundaries, partial first units, restart behavior, negative/overflow inputs and federation replay protection. A new public source file belongs in SOURCE_MANIFEST.json. Do not include private operating data.

Human counters, digital counters and network self-reports must remain separate. Avoid merit scores, competitive rankings, paid spiritual status and unsupported claims of machine realization.
